# Gaana Redesign — Frontend Application

This directory contains the React 19 + Vite frontend source code for the **Gaana Homepage Redesign Concept** (Acdyon Technologies Frontend Challenge — Part 2).

For complete project documentation, design decisions, and architecture overview, see the root documentation:
- [Root README.md](../README.md)
- [DECISIONS.md](../DECISIONS.md)

---

## Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
